# OFM-ClimateControl

Module for controlling two heating/cooling systems.

## Features

- Shared automatic mode for two heating/cooling systems
- Open-window handling
- Switching between summer and winter operation
- Calculation of the 24-hour average temperature
- Restoration of the configured mode, setpoint temperature, and latest outdoor temperature values after KNX bus power loss and device restart
